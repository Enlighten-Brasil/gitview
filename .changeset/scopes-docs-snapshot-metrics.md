Documentação do eixo de trabalho (produção × progresso) e harness versionado de regressão das agregações. Nova página de guia "Produção vs progresso" para gestores (EN + pt-BR): o que cada escopo mostra, os painéis que seguem/ignoram o `filters.workScope` (janelas fixas — inatividade especialmente) e as limitações conhecidas (dupla contagem do squash, `ref_hint` melhor-esforço, expurgo de fantasmas retroativo). O vocabulário triplo de escopo (`scope` de dados × `filters.workScope` × `FilterScope` de rota) vira tabela no AGENTS.md com as regras operacionais do workScope; o `?scope=` entra nas regras dos filtros (EN + pt-BR), com o grafo de commits na tabela de janelas fixas. `/branches` e o grafo de commits passam a ser referenciados no nav/sidebar do site de docs (páginas órfãs) e entram na lista de features dos dois READMEs. Varredura de contagens stale das ondas anteriores (4→6 coletores; 5→6 JSONs + `graph-*.json` por repo) em maintenance/publishing/development/READMEs. Novo `pnpm snapshot:metrics` (`scripts/snapshot-metrics.ts`): harness de regressão node/tsx puro que injeta o `stats.json` real no store e imprime JSON determinístico (chaves ordenadas, sem timestamp) de 18 cenários de filtros (6 bases × `all|prod|progress`) com a identidade aditiva `prod+progress==all` embutida (violação → exit 1) e `--now=YYYY-MM-DD` opcional para baselines estáveis entre dias — documentado no guia de desenvolvimento (EN + pt-BR).
